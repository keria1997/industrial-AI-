## 3. 页面通用模式

每个业务模块页面从上到下遵循统一结构：

### 3.1 模块标题栏

```
┌─────────────────────────────────────────────────────────────────┐
│  [图标方块]  模块名称                        [ 主操作按钮 ]      │
│              副标题文字                                          │
└─────────────────────────────────────────────────────────────────┘
```

- 图标方块：`w-12 h-12 rounded-xl`，带模块主题色背景（如 `bg-blue-100 text-blue-600`）
- 模块名称：20px `font-bold text-slate-900`
- 副标题：13px `text-slate-400`
- 操作按钮：`h-9 px-4 rounded-lg bg-blue-600 text-white text-[13px] font-medium`

### 3.2 页签导航

```
┌─────────────────────────────────────────────────────────────────┐
│  [📊 销售监控舱] [📄 产品报价] [📋 销售订单] [👤 客户管理] ...  │
└─────────────────────────────────────────────────────────────────┘
```

- 每个页签：`flex items-center gap-1.5 h-9 px-4 rounded-lg text-[13px] font-medium`
- 选中：`bg-blue-600 text-white`
- 未选中：`text-slate-600 hover:bg-slate-50`
- 页签内含 Lucide 图标（16px）+ 文字

### 3.3 统计卡片

```
┌────────────────────────────┐
│  标题              [图标]  │
│                            │
│  数值    单位              │
│                            │
│  辅助说明文字              │
└────────────────────────────┘
```

- 卡片：`bg-white border border-slate-200 rounded-2xl p-5 shadow-sm`
- 标题：13px `font-bold text-slate-500`
- 图标：`p-2 rounded-xl` + 模块主题色背景
- 数值：30px `font-bold text-slate-800 tabular-nums`
- 单位：14px `text-slate-400 font-medium`
- 辅助文字：12px（如绿色 `✓ 当前销倍订单总量`、红色 `⚠ 待发货超过3天`）

### 3.6 字典驱动下拉

下拉选项从平台字典 API 动态加载，不硬编码在代码中。用户在平台管理 → 字典中自行维护条目。

#### 数据流

```
平台管理 → 字典 → 新增条目（分类: equipment_type）
                  新增条目（分类: equipment_health_status）
    ↓
设备注册弹窗打开
    → GET /api/v1/platform/dictionaries?category=equipment_type
    → GET /api/v1/platform/dictionaries?category=equipment_health_status
    → 动态渲染 <option>
```

#### 规范

| 属性 | 说明 |
| --- | --- |
| 分类命名 | 小写蛇形（如 `equipment_type`、`equipment_health_status`） |
| 条目结构 | `{ category, code, name, status }` |
| 下拉为空时 | 显示"请先在平台管理 → 字典中配置"，允许保存时值为空 |
| 预置数据 | 不预置，由用户自行添加 |

#### 适用场景

- 生产管理 → 设备机台 → 硬件种类（分类 `equipment_type`）
- 生产管理 → 设备机台 → 健康状态（分类 `equipment_health_status`）
- 其他需要可配置下拉选项的场景
