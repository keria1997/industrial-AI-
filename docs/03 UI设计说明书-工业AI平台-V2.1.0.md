# UI 设计说明书 - 工业AI平台 V2.1.0

> 文档版本：`UI-DEVBASE-R20261015`
> 依据：`V2.1.0-PRD-DEVBASE-R20261015`（第 7 章功能需求 + 第 17 章开发就绪基线）
> 参照：当前前端实现（React 18 + Tailwind CSS 3 + Lucide React）
> 约束：本设计文档定义 UI 蓝图，不修改业务代码。

## 1. 设计目标与原则

### 1.1 设计目标

1. **角色聚焦**：每个角色进入工作台即看到与自己职责相关的核心指标、待办和风险，无需跨模块搜索。
2. **流程可追**：任何单据都能通过来源链接追溯至上下游模块，UI 中不出现"孤岛数据"。
3. **操作可逆**：关键操作有确认弹窗，不可逆操作提供二次确认和原因输入。
4. **状态清晰**：每个单据、任务、预警都有明确状态标签，颜色语义一致。
5. **低学习成本**：B 端用户熟悉表格 + 筛选 + 操作列的模式，不引入复杂交互范式。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 服务端权威 | 页面展示的数据全部来自后端 API，不使用本地种子数据兜底业务事实 |
| 无权限即隐藏 | 无权限的模块、页签、按钮在导航和操作区均不渲染，URL 直达返回 403 页 |
| 来源可穿透 | 列表行的"来源/目标单据"列可点击跳转到来源详情页 |
| 缺失不伪造 | 工作台金额、库存等指标缺失时显示"-"和"数据待接入"，不显示 0 |
| 反馈全覆盖 | 每个写操作有 loading、成功 Toast、失败提示和按钮防重 |
| 密度适中 | 表格行高 44px，卡片内边距 24px，信息层级 3 级（标题/副标题/正文） |

## 2. 全局布局

### 2.1 布局结构

平台采用左侧固定侧栏 + 右侧主内容区的经典 B 端布局。侧栏包含 Logo 和 13 个模块导航项；主内容区顶部是 64px 高的粘性顶栏（全局搜索、消息铃铛、AI助手入口、用户头像），下方是模块页面内容。

### 2.2 布局规格

| 区域 | 宽度/高度 | 背景色 | 说明 |
| --- | --- | --- | --- |
| 侧栏 | 300px（工作台）/ 256px（其他模块） | `#FFFFFF` | 左侧固定，桌面端始终可见 |
| 顶栏 | 高度 64px | `rgba(255,255,255,0.9)` + `backdrop-blur-md` | 粘性顶部，半透明模糊 |
| 主内容 | `flex-1`，自适应 | `#F8FAFC` | 浅灰背景，内容卡片白色 |
| 移动端 | 侧栏隐藏，通过汉堡菜单展开 | 同上 | `lg:` 断点以下 |

| 语义 | Tailwind 类 | 使用场景 |

#### 2.3.3 状态标签色板

| 状态 | 背景色 | 文字色 | 说明 |
| --- | --- | --- | --- |
| 待处理 / PENDING | `bg-amber-50` | `text-amber-700` | 需要用户操作 |

| 处理中 / POSTING | `bg-blue-50` | `text-blue-600` | 异步处理等待结果 |

## 4. 页面设计

### 4.1 登录页

全屏居中卡片，浅灰背景。支持密码登录和短信登录两种方式，底部提供"注册租户"和"忘记密码"链接。

登录成功后 Token 存入 `sessionStorage`，跳转到工作台首页。

### 4.2 工作台首页

#### 4.2.1 布局

页面从上到下分为四个区域：

1. **欢迎区**：问候语 + 用户名 + 当前角色 Badge
2. **指标卡片区**：根据角色显示不同指标卡片（5 列网格，响应式降为 2 列）
3. **预警与待办区**：左侧"来源业务预警"、右侧"待办清单"（2 列网格）
4. **动态与趋势区**：实时业务动态时间线 + 近 6 个月趋势图

#### 4.2.2 角色 × 指标矩阵

| 指标 | 老板 | 销售 | 计划员 | 采购 | 仓管 | 财务 |
| --- | --- | --- | --- | --- | --- | --- |
| 本月订单金额 | P0 | P0 | - | - | - | P0 |
| 确认收入 | P0 | P0 | - | - | - | P0 |
| 发货确权金额 | P0 | P0 | - | - | - | P0 |
| 排产交期达成量 | P0 | - | P0 | - | - | - |
| 物料低水位 | P0 | - | P0 | P0 | P0 | - |
| 未关闭预警数 | P0 | P0 | P0 | P0 | P0 | P0 |
| 今日待办数 | P0 | P0 | P0 | P0 | P0 | P0 |

无权限的指标不渲染卡片，不用灰色禁用态。

#### 4.2.3 指标卡片

每张指标卡片（`StatCard`）包含：标题（13px slate-500）、数值（30px slate-800 font-bold）+ 单位、图标（18px 带主题色圆角背景）、趋势指示（可选）。数值缺失时显示 `-` 和副文本"数据待接入"。

#### 4.2.4 来源业务预警

列表项包含：风险等级 Badge（高/中/低）、预警标题、来源单据号（可点击跳转）、相对时间。预警不可手动关闭，来源业务状态解除后自动消失。

#### 4.2.5 待办清单

列表项包含：优先级 Badge（P0/P1）、待办标题、责任人、截止时间、"去处理"按钮。逾期待办追加红色"已逾期"标记。待办不能在工作台手动关闭，只能通过来源模块完成业务动作后自动关闭。

#### 4.2.6 实时业务动态

时间线列表，每条包含：事件类型图标、事件描述、来源单据链接、相对时间。顶部分段控件切换"全部业务事件"和"关键事件"。

### 4.3 销售管理

#### 4.3.1 页面结构

页签导航包含 5 个子页：

| 页签 | ID | 内容 |
| --- | --- | --- |
| 监控舱 | `dashboard` | 销售指标卡片 + 趋势图 |
| 产品报价 | `quotes` | 报价列表 + 新建/编辑 |
| 销售订单 | `orders` | 订单列表 + 新建/详情/审批/确认/发货 |
| 客户管理 | `customers` | 客户列表 + 新建/编辑 |
| 基础数据 | `settings` | 客户等级、SLA 规则等字典 |

#### 4.3.2 销售订单列表

列表页从上到下：

1. **筛选栏**：搜索框、状态下拉、日期范围、"快速开单"按钮
2. **状态统计条**：待发货 / 已确认 / 部分发货 / 已发货 / 已完成 / 已取消（各带计数）
3. **订单表格**：列头 + 数据行 + 操作列

表格列定义：

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| 订单号 | 文本链接 | 点击打开详情 |
| 客户 | 文本 | 客户名称 |
| 状态 | Badge | 按状态色板渲染 |
| 总金额 | 数字右对齐 | 千分位 + 币种符号 |
| 交期 | 日期 | 逾期红色 |
| 已发/订购 | 进度文本 | 如 `4/10` |
| 操作 | 按钮组 | 按状态显示不同按钮 |

操作按钮规则：

| 操作 | 可见状态 | 权限码 | 行为 |
| --- | --- | --- | --- |
| 确认订单 | 待发货 + 审批通过 | `sales.order.confirm` | 打开确认弹窗，固化内容 |
| 去发货 | 已确认 | `sales.order.ship` | 创建仓库任务，弹窗提示成功 |
| 取消 | 待发货 + 未确认内容 | `sales.order.cancel` | 弹窗确认 + 原因必填 |
| 查看 | 所有状态 | `sales.order.read` | 打开订单详情侧滑 |
| 更多 | 部分发货/已发货 | - | 下拉菜单：RMA/签收/完成关闭 |

操作列使用 `sticky right-0` 固定在可视区右侧。

#### 4.3.3 订单状态标签

| 状态 | Badge 颜色 | 中文 |
| --- | --- | --- |
| `PENDING_CONFIRMATION` | amber | 待发货 |
| `CONFIRMED` | blue | 已确认 |
| `REPLENISHING` | purple | 生产补货中 |
| `PARTIALLY_SHIPPED` | blue | 部分发货 |
| `SHIPPED` | emerald | 已发货 |
| `COMPLETED` | emerald | 已完成 |
| `CANCELED` | slate | 已取消 |

#### 4.3.4 订单详情侧滑面板

从右侧滑入（Desktop），包含以下区域从上到下：

1. 基本信息：订单号、客户、状态、总金额、交期、审批状态
2. 行明细表格：产品、数量、已发/未发、单价、折扣、金额
3. 履约追踪：仓库任务状态、预留量、出库记录、生产需求、工单链接
4. 财务信息：AR 金额、已回款、待核销（完成发货后显示）
5. 操作日志：时间线格式，含 Correlation ID 和 Trace ID（可展开）

#### 4.3.5 快速开单弹窗

表单字段：

| 字段 | 类型 | 校验 |
| --- | --- | --- |
| 客户 | 下拉搜索 | 必选 |
| 仓库 | 下拉 | 默认客户默认仓库 |
| 产品明细 | 行编辑表格 | 至少 1 行，每行数量 > 0 |
| 折扣率 | 数字输入 | 默认 100，范围 0~100 |
| 优惠金额 | 数字输入 | >= 0 |
| 备注 | 文本域 | 可选 |

产品明细行内字段：产品（下拉搜索）、数量（数字 > 0）、单价（数字 > 0）、可用量（只读，显示当前事实版本可用量）。

提交按钮"创建订单"，提交中禁用防重；成功后关闭弹窗并跳转到订单列表选中"待发货"。

### 4.4 库存管理

#### 4.4.1 页面结构

| 页签 | ID | 内容 |
| --- | --- | --- |
| 库存看板 | `dashboard` | 总量、预警、分布统计卡片 |
| 现存量台账 | `stock` | 按仓库/产品/物料查询 |
| 出库管理 | `outbound` | 销售出库任务列表 + 过账 |

#### 4.4.2 现存量台账

筛选栏：仓库下拉 + 类型切换（全部/产品/物料）+ 关键词搜索 + 健康度筛选。

表格列：

| 列名 | 说明 |
| --- | --- |

| 对象名称 | 名称 |
| 仓库 | 所属仓库 |
| 类型 | 产品/物料 Badge |
| 现存量 | 数字 |

#### 4.4.3 出库管理

任务列表列：来源订单（链接）、产品、剩余量、可用量、状态 Badge、操作按钮。

确认发货弹窗：

显示订单号、产品名、剩余量、可用量。用户输入本次发货数量（数字输入）。如果可用量 < 剩余量，显示警告提示"库存不足，仅可发 X"，主按钮文字变为"确认部分发货"。如果可用量为 0 且无预留，主按钮变为"去生产"（紫色高亮）。

点击"去生产"后确认弹窗显示缺口数量，确认后创建生产需求，Toast 显示需求编号，任务状态变为"生产补货中"。

#### 4.5.5 成本归集查询

| 成本项 | 金额 | 来源 |
| --- | --- | --- |
| 直接材料 | 领料出库流水金额 | 领料出库 |
| 直接人工 | 报工记录金额 | 报工 |
| 制造费用 | 分摊规则计算 | 资源占用 |
| 质量成本 | FQC 返工/报废金额 | FQC |
| 退料冲减 | 负向金额 | 退料入库 |
| 工单总成本 | 自动汇总 | 以上合计 |

## 5. 组件规范

### 5.1 按钮

| 变体 | 样式 | 用途 |
| --- | --- | --- |
| Primary | `bg-blue-600 text-white hover:bg-blue-700` | 主操作（确认/提交/创建） |
| Secondary | `bg-white text-slate-700 border border-slate-300 hover:bg-slate-50` | 次操作（取消/返回） |
| Danger | `bg-rose-600 text-white hover:bg-rose-700` | 危险操作（删除/取消/冲销） |
| Ghost | `text-blue-600 hover:bg-blue-50` | 行内操作（查看/编辑） |
| Disabled | `opacity-50 cursor-not-allowed` | 不可操作 |

按钮尺寸：高度 36px（`h-9`），文字 13px，内边距 `px-4`。

### 5.2 输入框

复用 `.prod-input` 样式类：

- 高度 40px
- 边框 `1px solid` 灰色，圆角 `12px`
- 聚焦时蓝色边框 + 3px 蓝色阴影环
- 错误时红色边框 + 红色阴影环，下方显示错误文字

### 5.3 表格

复用 `.prod-table` 样式类：

- 列头：灰色背景，字号 11px，字重 semibold
- 行：白色背景，底部 1px 灰色边框
- 悬停行：浅蓝色 `hover:bg-blue-50`
- 操作列：`sticky right-0` 固定

### 5.4 弹窗（Modal）

- 遮罩层：`bg-black/50`
- 弹窗容器：`bg-white rounded-2xl shadow-xl max-w-lg mx-auto`
- 标题栏：标题 18px bold + 关闭按钮（X 图标）
- 底部按钮区：右对齐，主按钮 + 次按钮
- 打开时锁定 body 滚动；Esc 或点击遮罩关闭（危险操作弹窗除外）

### 5.5 Toast

- 位置：右上角固定
- 类型：成功（绿）/ 错误（红）/ 警告（橙）/ 信息（蓝）
- 自动消失：3 秒
- 不阻断操作

### 5.6 状态标签（Badge）

样式：`inline-flex items-center rounded-full px-2.5 py-0.5 text-[11px] font-semibold`，颜色按语义色板选择。

### 5.7 空状态

居中显示 Inbox 图标 + "暂无数据" + 副文本 + 可选"清空筛选"按钮。图标和文字使用 `text-slate-400/500`。

### 5.8 加载状态

- 页面级：骨架屏（灰色圆角块模拟卡片和表格形状）
- 按钮级：按钮内显示旋转图标 `Loader2`，禁用点击

### 5.9 错误状态

- API 401：清除会话，跳转登录页
- API 403：显示"无权限"页面 + "返回工作台"按钮
- 其他错误：Toast 或页面内错误面板，含错误码和重试按钮

## 6. 响应式设计

### 6.1 断点

| 断点 | Tailwind | 宽度 | 布局 |
| --- | --- | --- | --- |
| Mobile | `< lg` | < 1024px | 侧栏隐藏，汉堡菜单；卡片单列 |
| Desktop | `>= lg` | >= 1024px | 侧栏固定；卡片网格 |

### 6.2 表格处理

- Desktop：完整列展示，操作列 `sticky right-0`
- Mobile：关键列优先，非关键列隐藏；操作折叠为"更多"下拉

### 6.3 弹窗处理

- Desktop：居中弹窗 `max-w-lg`
- Mobile：全屏覆盖或底部滑出

## 7. 交互细节

### 7.1 确认弹窗

危险操作（删除、取消、冲销）必须弹窗确认，包含：警告图标、说明文字、原因输入框（必填）、"返回"和"确认"按钮。原因未填时确认按钮禁用。确认按钮使用 Danger 样色。

### 7.2 更多操作菜单

触发：点击 `MoreVertical` 图标。弹出层出现在按钮下方右对齐。关闭方式：点击外部、按 Esc、选择菜单项。菜单内点击通过 `stopPropagation` 避免误关。

### 7.3 面包屑与返回

详情页顶部显示面包屑：`销售管理 > 销售订单 > SO-001`。点击上级层级返回列表页并保留筛选条件。

### 7.4 URL 深链接

详情页通过 `?module=sales&tab=orders&focus={orderId}` 直接访问。刷新后从服务端恢复数据。无权限的深链接返回 403 页。

## 8. 无障碍

| 规则 | 实现 |
| --- | --- |
| 语义化标签 | 使用 `<button>` `<table>` `<nav>` `<main>` 等原生元素 |
| 键盘导航 | Tab 焦点顺序符合视觉顺序 |
| 焦点样式 | 聚焦时 `ring-2 ring-blue-500` |
| ARIA | 图标按钮 `aria-label`；错误输入 `aria-invalid="true"` |
| 色彩对比 | 正文 >= 4.5:1 |
| 屏幕阅读器 | 状态标签 `role="status"`；Toast `aria-live="polite"` |
