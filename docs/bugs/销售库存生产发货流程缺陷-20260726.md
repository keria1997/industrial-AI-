# 销售—库存—生产—发货流程缺陷

## BUG-WF-20260726-001 仓库库存校验前销售订单提前进入已确认

| 项目 | 内容 |
| --- | --- |
| 严重级别 | P0 / 阻断 |
| 状态 | 开发已修复，待 QA 复验；审批、发货申请、仓库确认状态已分离，审批后编辑会重置待审批 |
| 涉及需求 | PRD 5.1、5.2、7.3.9.2；UC-012 |
| 影响 | 订单在无预留、无正式出库单且实际缺货时被标记为已确认，可能误导销售和仓库认为货源已锁定 |

**复现步骤**

1. 打开销售订单 `SO-20260508-001`，确认状态为待确认、FG001 × 17。
2. 打开更多操作，点击“确认订单”并再次确认。
3. 观察订单立即变为“已确认”。
4. 前往库存出库管理，观察可用量为 8、缺口为 9。

**实际结果**：销售菜单缺少独立复核/审批和“发起发货”；“确认订单”同时移交仓库并提前把总体状态置为已确认。

**期望结果**：复核/审批只更新独立状态，总体保持待确认；销售执行“发起发货”后总体仍待确认；只有仓库库存校验、预留和出库单创建成功后才进入已确认。

## BUG-WF-20260726-002 正式生产需求在 MPS/MRP 阶段退化为本地原型

| 项目 | 内容 |
| --- | --- |
| 严重级别 | P0 / 阻断 |
| 状态 | 开发已修复，待 QA 复验；生产主入口已接正式作业台，Reference MPS/MRP/APS 结果和工单候选前置已实现，不代表客户优化器 |
| 涉及需求 | PRD 5.2 第 6、9 步；UC-020~029、UC-100；TASK-FE-002~004 |
| 影响 | 正式缺货需求不能形成正式生产计划、工单和完工结果，销售补货永久停滞 |

**复现步骤**

1. 在库存为 `SO-20260508-001` 创建正式需求 `DM-MS1KE6IT202B`，缺口 9。
2. 进入生产管理 → 主计划(MPS)，确认需求已出现在需求池。
3. 点击该行“生成MPS”。
4. 进入运算控制台，点击“执行全局 MRP 展算”。

**实际结果**：需求状态只在旧版页面变为“已生成MPS”；MRP 仍展示种子 `MPS-26001/26002`，没有该需求的计划或计算结果；执行动作只有成功 Toast。

**期望结果**：正式需求通过生产 API 完成校验/审批、创建可追溯 MPS/MRP 任务及结果，并继续形成工单；任务记录、求解完成和业务结果必须分开呈现。

## BUG-WF-20260726-003 补货完成后无重新校验与发货闭环

| 项目 | 内容 |
| --- | --- |
| 严重级别 | P0 / 阻断 |
| 状态 | 开发已修复，待 QA 复验；完工事件会推进 Reference 库存事实并唤醒关联任务重新校验，页面提供重新校验和后续发货动作 |
| 涉及需求 | PRD 5.1、7.5.4、7.5.5、7.5.9；UC-012、UC-028、UC-100 |
| 影响 | 生产申请中的销售出库任务无法恢复到待出库，订单不能达到首期验收终点 `SHIPPED` |

**实际结果**：当前生产主入口无法从本次需求完成报工、FQC 和成品入库；库存任务处于“生产申请中”时只提供“查看生产申请”，没有 PRD 要求的“重新校验”。

**期望结果**：完工入库产生并关联新版本库存事实；原出库任务允许重新校验，缺口归零后创建/补足预留与出库单并进入待出库，仓库确认后回写销售发货状态。

## BUG-WF-20260726-004 销售与库存种子单据编号及数量断链

| 项目 | 内容 |
| --- | --- |
| 严重级别 | P1 / 高 |
| 状态 | 开发已修复，待 QA 复验；孤立历史种子已锁为只读，正式后端按销售订单/行 UUID、版本、产品、数量和仓库校验 |
| 涉及需求 | PRD 5.1 可追溯要求、7.5.4 销售出库字段；UC-100 |
| 影响 | 仓库可能对不存在或错误数量的订单发起生产申请、拣货或发货 |

**实际结果**：销售订单为 `SO-20260615-001`、FG001 × 1；库存出库单 `OUT-260702-02` 却关联 `SO-260615`、FG001 × 50。点击“去发货”后弹窗继续使用错误的 50 PCS 缺口。

**期望结果**：来源订单号、来源行、产品、申请量与销售订单快照一致；无法解析到正式销售订单的孤立种子任务不得进入生产或发货动作。

## BUG-WF-20260726-005 缺少部分发货和剩余发货能力

| 项目 | 内容 |
| --- | --- |
| 严重级别 | P1 / 高 |
| 状态 | 开发已修复，待 QA 复验；页面支持本次发货数量、部分发货和剩余发货，数量守恒已有 API 与前端测试 |
| 涉及需求 | PRD 7.3.9.2、验收条款 1863~1865；UC-012 |

3. 需求池表格"来源/客户"列下方新增来源销售订单号、订单行、出库任务和库存事实版本显示行。
4. `handleViewDemandSource` 点击"来源"按钮时展示完整溯源信息（来源类型、销售订单、订单行、出库任务、库存事实版本、Correlation ID、Trace ID）。
