## 4. 本轮安全可接入的契约同步

1. 工作台只接受 1.1 嵌套 data；兼容已声明的字段别名，优先读取最新 canonical status/errorCode、兼容 availability/unavailableReason，避免 undefined；无币种/税口径的金额显示 -，不将裸值“元”当权威分组事实。移除考勤指标；保留稳定事件 ID 校验。
2. 400 WORKBENCH_400_INVALID_CURSOR 时丢弃该历史请求，恰好重取一次第一页，不把旧历史继续拼接、不无限重试。
3. 资源查询使用 permission-resources；审计使用真实 total/hasMore，不再写“总数待确认”或以当页长度推断下一页。
4. 适配器 NOT_CONFIGURED 回读后显示未配置提示；其他同步结果显示接口返回状态并要求核对外部结果，不额外编造外部成功事实。
5. 财务确认读取同一 Payment 的 Allocation 才显示“已确认并生成系统核销事实”，不追加第二次核销请求；款项/父级财务数据仍按既有刷新链回读。
6. 请求统一发送 canonical Idempotency-Key，并在兼容阶段保留相同 X 头。两者冲突时不发请求；登录展示后端锁定建议，不新增前端解锁模拟。

生产完工、RMA/签收续办和财务冲销仍受上述来源/守卫阻断，未强行开放。现有主数据容量/价格/安全库存默认语义等原报告待确认项，也不因六项修复而自动销项。整个前端剩余实施范围仍以原计划和 PRD 为准。
