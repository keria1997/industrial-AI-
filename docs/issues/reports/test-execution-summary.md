## 5. 链路断路分析

3 个根因缺陷（DE-03 × DE-04 × DE-05）叠加导致业务闭环点火路径全部断路：

```
销售快速开单 ✗ DE-03 产品下拉为空
  └→ 销售订单 0 单
      └→ 缺货建需 0 笔
          └→ MRP 展算 ✗ DE-05 按钮空函数
              └→ PR 0 → PO 0 → 收货 0

库存建立 ✗ DE-04 手工入库空函数
  └→ 现存 0 → 出库 0 → 签收 0 → AR 0 → 核销 0
  └→ RMA 0（依赖原出库行）

生产工单 0（依赖缺货需求）→ 完工入库 0 → 成本核算 0
```

**无法绕过的原因：**
- 销售订单页无"新建订单"按钮，只能经快速开单 → 被 DE-03 阻断
- 报价单明示"持久化接口尚未接入" → 报价转单不可用
- 产品编辑弹窗"库存归属仓库"字段 disabled → UI 无配置入口
