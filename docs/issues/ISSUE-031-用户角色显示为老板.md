# ISSUE-031：用户角色为租户管理员但界面显示为老板

- 级别：P1 体验
- 模块：工作台 / 认证
- 层级：L4 基础层
- 影响范围：前端, 后端
- 状态：🔴 待修复

## 问题

用户 `liyi` 在数据库中的主岗位为"租户管理员"，但左下角和工作台主页均显示为"老板 · 经营驾驶舱"。角色名称与实际岗位不一致。

复现步骤：
1. 使用 `liyi` 账号登录
2. 查看左下角用户信息 → 显示"老板 · 经营驾驶舱"
3. 进入工作台 → 角色Badge 显示"老板 · 经营驾驶舱"
4. 进入平台管理 → 员工与账号 → 主岗位显示"租户管理员"

## 原因

后端登录接口 `AuthController.login()` 返回的 `role` 字段为 `"老板"`（developmentUser 或 registeredUser 的 role 字段值），而非数据库 `iam_employee` 表中记录的主岗位"租户管理员"。

前端 `App.tsx` 直接使用后端返回的 `session.role` 设置 `activeRole`，未从员工档案中查询实际岗位。

## 方案

| 修改层面 | 文件 | 具体改动 |
|---|---|---|
| 后端 | backend/src/main/java/com/wanshen/platform/auth/AuthController.java | 登录成功后查询员工档案获取主岗位，返回实际岗位而非硬编码"老板" |
| 前端 | frontend/src/App.tsx | 无需修改（已正确使用后端返回的 role 字段） |

## 验收标准

1. 登录后左下角显示实际主岗位（如"租户管理员"）
2. 工作台角色Badge 显示实际主岗位
3. 平台管理中的岗位信息与侧栏/工作台显示一致
