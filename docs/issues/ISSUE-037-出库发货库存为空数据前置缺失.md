# ISSUE-037：出库发货时库存为空，数据前置缺失

- 级别：P1
- 模块：销售管理 → 出库管理
- 层级：L1 业务域层
- 影响范围：前端
- 状态：🟢 正常行为（数据前置缺失，非 bug）

## 问题

出库管理发货时选择仓库 `saa (AAA)` 后提示：

> saa未查询到以下产品的库存记录： ssa（SAS）。请核对来源入库单据是否已过账；办理采购收货或生产完工入库后，重新查询库存。

## 原因

数据库中无该产品在该仓库的库存可用量记录（`module_document` 中无 availability 类型数据）。系统正确阻止了无库存发货。

**这是数据前置缺失，非代码 bug。** PRD 7.5.9 出库守卫要求：不可用量为 0 时禁止出库。

## 现状

错误信息质量已改善（关联 ISSUE-018 DEF-A）：
- ✅ 显示产品名称 `ssa（SAS）` 而非 UUID
- ✅ 提供操作指引"办理采购收货或生产完工入库"
- ✅ 提供"重新查询库存""查看库存台账""查看入库办理指引"三个操作按钮

## 解决方案

无需修改代码。用户需通过以下方式添加库存：

1. 库存管理 → 手工入库（需 ISSUE-018 DEF-D 修复弹窗渲染后可用）
2. 采购管理 → 采购收货（需先创建 PR/PO）
3. 生产管理 → 完工入库（需先有工单）

## 进展

🟢 正常行为（等待数据前置完成后自动解除）
