# ISSUE-019：生产需求校验阻断（缺少 BOM）+ 暂缓审批未开放 + Toast 展示时间过短

> 发现日期：2026-10-17
> 环境：http://124.222.114.67/（部署环境）
> 模块：生产管理 → 主计划 (MPS)
> 级别：P1 功能阻断 + P2 体验
> 状态：**新增**

## 问题描述

生产管理 → 主计划 (MPS) 页面中，对生产需求执行"校验"操作时出现两个问题：

1. **红色错误 Toast**：`生产需求 [DM-MVCBRHE4D10A] 校验阻断：缺少服务端生效 BOM`
2. **橙色警告 Toast**：`该需求仍保留服务端状态，暂缓审批尚未开放`
3. **Toast 展示时间过短**：约 3 秒后自动消失，用户来不及阅读完整错误信息

## 问题 1：校验阻断 - 缺少服务端生效 BOM

### 根因

后端 `ProductionService.java` 第 295 行校验逻辑：

```java
if (bom == null) missing.add("缺少服务端生效 BOM");
```

生产需求校验要求该产品必须有一条**已发布（生效）的 BOM**。当前数据库中该产品（`DM-MVCBRHE4D10A` 对应的产品）没有已发布的 BOM 记录。

### 数据链路

```
生产需求校验（POST validate）
    → ProductionService.validate()
    → 查询 BOM 快照（bom-snapshots）
    → bom == null → 阻断
```

### 解决方案

**数据操作**（用户操作）：
1. 进入 生产管理 → BOM 管理
2. 为该产品创建 BOM（添加物料子项）
3. 发布 BOM（状态改为"已生效"）
4. 返回 主计划 → 重新校验需求

**前提**：BOM 管理页签需可正常创建和发布 BOM。

## 问题 2：暂缓审批尚未开放

### 代码定位

**文件**：`frontend/src/App.tsx` 第 5074 行

```typescript
showToast('该需求仍保留服务端状态，暂缓审批尚未开放', 'warning');
```

### 根因

"暂缓审批"（Hold Demand）功能在前端为占位按钮，点击后直接弹出此提示。后端 API `POST /api/v1/production/demands/{id}/hold` 尚未实现或未对接。

### 解决方案

需要后端实现 hold API 并在前端对接。当前不影响主流程（校验 → 审批 → 接收 → MRP），仅影响异常暂停场景。

## 问题 3：Toast 展示时间过短

### 代码定位

**文件**：`frontend/src/App.tsx` 多处

```typescript
setTimeout(() => setToast({ show: false, msg: '', type: 'success' }), 3000);
```

Toast 持续时间为 **3 秒**，用户要求增加至 **5 秒**。

### 修改方案

**涉及位置**（3 处）：

| 行号 | 模块 | 当前值 | 修改为 |
|---|---|---|---|
| 4712 | 销售管理 | 3000 | 5000 |
| 6478 | 生产管理 | 3000 | 5000 |
| 9489 | 采购管理 | 3000 | 5000 |

**修改方式**：全局替换 `3000` 为 `5000`（仅 toast 相关的 `setTimeout`）。

## 修复优先级

| 优先级 | 问题 | 类型 |
|---|---|---|
| P1 | 校验阻断缺少 BOM | 数据前提（需先创建 BOM） |
| P2 | 暂缓审批未开放 | 功能未实现 |
| P2 | Toast 时长 | 前端 UX 改进（改 3 处 `3000` → `5000`） |

## 临时操作指引

用户可按以下步骤解除 BOM 校验阻断：

1. 生产管理 → BOM 管理
2. 为需求对应的产品创建 BOM
3. 发布 BOM（状态改为已生效）
4. 返回 主计划 → 校验需求 → 应通过校验
