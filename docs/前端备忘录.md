## 2026-10-17 正式 API 替代原型存储（续）

- 本轮目标：删除运行时业务 Storage 桥接，接入已存在的库存主数据、客户、平台等接口；清理仅保留登录/租户偏好/正式请求幂等和查询索引。
- 已核实的契约限制：报价单 CRUD/转单未提供；库存直接补货 PR 现有创建接口仅接受正式 MRP 任务、需求、物料；生产领料任务、设备、工艺维护缺少对应接口；产品/物料删除缺少接口。
- 主数据字段限制：产品/物料 PATCH 不接受 defaultWarehouseId、traceMode、procurementType，不能声称已保存这些配置。通用字典不承载客户等级阈值、颜色、排序与行业层级；触达规则缺少专用契约。
- 平台需区分真实路径：集合 POST、实体 PUT /{id}；租户资料维护、适配同步、撤销任意账号全部会话不能依据当前 client 声明就视为服务端已支持。
- 上一节“未接入项”是上一轮状态，具体本轮交付与验证记录在本节后续补充。不得据此认定全业务需求已开发完成。
- 已对接：产品/物料 POST 与 PATCH、客户 CRUD、平台单实体保存后重查快照、采购收货与生产完工入库查询、库存补货创建正式生产需求。发货只保留正式预留/过账流程，删除本地出库及销售状态桥接。
- 删除：旧业务 Storage 读写帮助函数、联动示例单生成、模拟工艺/BOM/设备/委外/退料保存成功；用正式 API 回归覆盖替代已退役的本地桥接测试。BOM 不再预填示例物料；采购审批必须选择正式供应商，去掉写死供应商和绩效百分比。
- 后端依赖清单（本轮不修改后端）：报价 CRUD/转单；销售等级完整属性与行业层级；触达配置；库存直接补货 PR；生产领料/退料；设备维护；独立工艺库维护；委外收发与工序转线；产品/物料删除与默认仓库/追溯/采购策略字段；企业资料/初始化状态维护；权限适配预检/同步；指定账号全部会话撤销；供应商绩效统计。BOM 中的关联工艺快照发布已有接口，不等于独立工艺库 CRUD。
- 浏览器按访问源隔离；对应地址加载新版后会自动清除历史原型，切回页面和其他标签页写入时再次清理。接口若仍返回旧记录，应核查其后端来源，不继续删除数据库数据。
- 本轮验证：`npm run typecheck`、`npm run test:frontend`（28 个文件、133 项测试）和 `npm run build` 通过；删除的测试仅针对已退役本地桥接，新增正式保存/版本/错误传播/主数据映射回归。
- 浏览器验证：`npm run test:prototype-storage` 在开发服务与生产预览均通过；每次覆盖 27 个页面的空响应和 503 场景，合计 108 次页面检查。另验证接口客户/产品非空展示、客户 PATCH 携带租户与版本、403 不更新列表并保留草稿、成功保存后刷新恢复、后续空/错误响应清除旧列表，且不回写原型键。
- 验证边界：Playwright 使用受控 API 响应，未执行本轮数据库全链路验收，也未迁移或清理数据库中的历史数据。构建仍有现有混合静态/动态导入与包体积提示，不影响本轮构建通过。

## 2026-10-17 原型缓存反复出现的修复

- 根因：入口仅清除 4 个固定版本 localStorage 前缀，遗漏 sessionStorage、历史版本与库存 workflow、平台状态；模块挂载会自动回写快照，库存异常解析与生产初始化还会恢复代码内种子。
- 处理：入口扫描两个存储区域的退役业务键；开发与生产均阻止退役键重新读写；移除销售、生产、平台的自动业务快照保存。
- 固定数据：清空主应用 23 组示例数组与生产原型 5 组记录；移除库存主数据及平台种子回退。测试数据隔离至 `frontend/src/app/tests/fixtures/`。
- 正式数据：销售选品与库存主数据从正式库存 API 加载；平台使用完整 API 快照，不再仅覆盖角色、权限后混入示例组织及员工。
- 保留：登录会话、租户选择、出库幂等信息、正式生产记录 ID 索引；不删除数据库任何记录。浏览器缓存按访问源隔离，访问对应地址并刷新后自动执行清理。
- 未接入项：平台管理中仍只在内存更新的旧保存动作，以及库存产品/物料编辑器中的本地保存/删除，不再冒充持久化成功，显示未保存/未删除提示。本次未修改后端，也未宣称上述功能已完成 API 对接。
- 仓库归属：产品/物料没有库存事实时，不伪造默认仓库；多仓事实无法确定唯一默认仓库时也不任取第一仓。默认仓库配置和按仓选品仍需按正式接口契约继续完善。
- 验证：156 条前端单元测试、类型检查和生产构建通过；`npm run test:prototype-storage` 在开发服务和生产预览分别验证 11 个页面的接口空数据/不可用场景，共 44 次页面检查通过。浏览器测试使用受控 API 响应，不代表完成数据库端到端验收。
