# 销售已发货同步出库验收

日期：2026-10-13。需求：销售订单从待发货经履约进入已发货后，出库管理可查询关联的已完成出库订单。

## 实现

- 历史本地订单保存为已发货时，同步持久化已完成出库记录；直接进入出库管理时恢复遗漏记录。
- 按来源订单复用已有单据，保留单号和已存在的出库事实；多产品数量按明细合计，兼容 `qty` 和 `quantity`。
- 重复刷新和确认收货不新增单据、不再次扣库存。待发货、已确认、部分发货及已取消订单不补成全量出库。
- 正式订单不生成本地替代单据，继续读取服务端任务和出库事实；正式来源覆盖同源本地记录。获得页面焦点或收到履约变化时重新加载。
- 已完成记录支持查看和凭证下载，不再展示去发货。历史恢复写入失败时仍可读取既有出库记录。

未新增 API、后端状态或数据库迁移。历史补齐属于租户隔离的本地兼容能力，不代表正式历史数据修复。
