# 销售至出库全业务流测试报告

## 1. 测试结论

**结论：不通过。**

本轮在 `http://127.0.0.1:4174/` 实际创建销售订单，并执行销售发货、库存校验、缺货生产申请、生产需求校验/审批、MPS/MRP、采购申请/订单、采购入库、生产报工/FQC/成品入库和销售出库回查。

## 4. 缺陷与阻断

### BUG-E2E-001 P0 正式待发货订单缺少“去发货”动作

- 实际：新建正式订单映射为“待发货”，动作规则只处理旧状态“待确认”，页面只显示复制/取消，无法移交仓库。
- 处理：本轮已修复 `getSalesOrderActions`，为“待发货”复用正式订单复核/发货动作规则，并补充 `NOT_REQUIRED` 回归用例。
- 复测：`SO-20260726-23B17D4D` 成功显示“去发货”，并完成发货申请。

### BUG-E2E-002 P1 出库任务校验前后编号变化

- 校验前定位任务：`67ee4731-45b4-4606-bfce-f4af014838be`。
- 校验后正式任务：`9f6e1d9a-62a5-46ad-a101-fce6452cb76a`。
- 风险：同一用户操作过程出现两个任务编号，审计追踪和问题定位容易误判；界面应解释临时定位记录与正式任务的关系，或保持稳定编号。

### BUG-E2E-003 P0 正式 MRP 结果未生成采购申请和生产工单

- 正式任务 `8bf83d86-dd82-495c-b9d8-145f56afb989` 完成后，运算控制台仍只展示固定 `MPS-26001/26002` 数据。
- 采购按钮仅显示“已推送外围 ERP”提示，没有新增 PR；订单与齐套页也没有本次需求对应工单。
- 影响：业务链从正式生产计划开始断裂，后续只能操作无来源关联的原型数据。

### BUG-E2E-004 P0 采购送货未生成可查询库存收货任务

- `PO-260706-001` 登记送货后提示“库存收货任务已生成”，但采购订单状态仍为“供应商确认”，库存入库流水没有新增对应任务。
- 影响：Toast 与实际业务事实不一致，采购到货不能自动进入仓库验收。

### BUG-E2E-005 P0 生产成品入库未更新正式库存事实

- 原型成品入库生成 `STK-IN-79490855`，但正式销售出库任务仍为可用 120、缺口 31、生产申请中。
- 影响：无法触发补货完成后的库存再校验、预留和销售出库。

## 6. 验收建议

1. 将正式 MRP 结果消费为带 `demandId/orderId` 来源关系的 PR 和生产工单，采购与生产页面必须查询正式台账。
2. 采购送货应生成可查询的收货/质检任务，并在验收后发布版本化库存事实。
3. 正式成品入库应更新 FG001 库存投影，驱动销售出库任务自动或人工再校验。
4. 补齐“生产补货完成 → 再校验 → 预留 → 全量/部分发货 → 销售状态回写”的自动化端到端测试。
