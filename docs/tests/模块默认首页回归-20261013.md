# 模块默认首页回归

日期：2026-10-13。需求：点击模块主导航时默认打开第一个页面，有监控舱的模块打开监控舱；后续等待或业务数据恢复不应改变当前页面。

## 原因与修复

- 原导航只更新模块名称与 URL，模块和 URL 相同的再次点击无法重置财务、人员等模块内部页签。增加 `moduleNavigationRevision`，业务内容按租户和导航版本重新初始化；先写目标 URL，再更新 React 状态。
- 生产和库存的业务流同步 effect 会同时更新数据与当前页签，历史计划异步恢复后覆盖监控舱。移除数据同步的选页副作用，用户明确业务动作通过 `query` 声明目标。
- `production=plan` 业务深链接兼容进入 MPS；刷新和浏览器历史保留明确目标，主导航清除旧页签与单据定位。相同默认 URL 的重复点击不增加重复历史记录。
