# 销售修改真实部署验收

用户要求：将销售发货权限、快速开单及空测试订单行修改落实到前端 5175、后端 8081。

已部署地址：`http://127.0.0.1:5175`，Java API 为 `http://127.0.0.1:8081`。前端为 nginx 提供的构建资源，代理访问 Java；数据存储为本地 PostgreSQL `industrial_ai`。两个直接/代理健康接口均返回 `ok`，前端脚本内容与当前发布包一致。

## 本次范围

- 无库存模块权限或缺少 `inventory.shipment-task.read`/`*` 时隐藏“进入出库管理”；销售用户仍能申请发货、关闭弹窗并停留原页面。
- 快速开单共用新增报价单的完整表单，直接创建待发货订单，不生成报价、发货申请或仓库任务。
- 开单日期、有效期、备注、产品名称/规格随正式订单保存到 Java/JDBC JSONB，列表/详情以服务端字段为准；历史浏览器快照仅作兼容。日期校验、1000 字备注上限、200 字名称/规格上限和 PATCH 合并校验已实现。
- 截图中的空单号“业务来源 / 0”来自流程占位信息，缺少来源订单号时不再生成销售列表行。验证保留已有订单及有效来源订单，没有删除其他数据库订单。
