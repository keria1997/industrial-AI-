# 手机号验证码获取修复验收

2026-10-14，北京时间。实现提交 `cdec2c5`、`60709db`；最终部署前端5175/7175、Java/PostgreSQL后端8081。

## 修复内容

获取验证码不再要求手机号预先绑定账号。有效手机号可调用真实短信服务；已绑定禁用账号仍返回403。获取验证码不创建账号或签发会话；短信登录仍要求绑定启用账号，未知手机号不映射演示管理员。

真实发送发现火山引擎成功响应不包含旧Code字段时被误报INVALID_RESPONSE。现兼容省略Code的成功响应；如存在Code则必须为0。仍要求HTTP成功、无ResponseMetadata.Error、有效RequestId和非空文本MessageID数组，缺少受理凭据或明确失败仍返回424。

验证码只在受理成功后写入数据库，5分钟有效、一次性使用；发送频率限制和旧码替换规则保留。密钥保持在Git忽略的本机环境文件中，权限600；正式响应不返回验证码。

## 操作步骤

1. 刷新5175或7175，选择“手机号登录”。
2. 输入有效手机号，点击“获取验证码”，发送成功后查看最新短信；60秒后可重新获取。
3. 验证码5分钟有效。登录需要该手机号已绑定启用账号；未注册的手机号可获取验证码，但需先注册账号或完成账号绑定才能登录。
