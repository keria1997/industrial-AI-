## 4. 缺陷清单

### BUG-V211-FUNC-001 P0 销售“保存并去发货”无法通过有效交期校验

- PRD 依据：7.3.5、7.3.6、7.3.8；承诺交期必填且不得早于订单日期，合法后应生成或恢复仓库出库任务。
- 前置数据：订单 `SO-20260726-2872`，订单日期 `2026-07-26`。
- 步骤：进入销售订单，点击“去发货”；空交期提交后出现“请选择交期”；填写 `2026-08-15`，再次点击“保存并去发货”。
- 实际结果：合法日期已显示在字段中，但错误提示未清除，弹窗不关闭，也未形成仓库任务。
- 预期结果：清除字段错误，提交发货申请并跳转库存出库管理。
- 证据：[销售交期校验截图](evidence/v211-sales-shipment-due-validation-1280x720.png)

### BUG-V211-FUNC-002 P0 库存确认发货后未回写销售订单

- PRD 依据：5.1、7.3.5.2、7.5.5、13.1；全部出库后销售订单应进入已发货并锁定。
- 前置数据：库存出库单 `OUT-260702-02`，来源订单 `SO-20260615-001`，数量 1。
- 步骤：库存管理进入出库管理，点击“去发货”，确认发货；再回到销售订单查询来源订单。
- 实际结果：库存单已变为“已完成”，销售订单仍为“未发货 / 已确认”。
- 预期结果：销售订单累计已发数量更新为 1，总体状态和发货状态更新为已发货。
- 证据：[库存完成截图](evidence/v211-inventory-shipped-1280x720.png)、[销售未回写截图](evidence/v211-sales-status-not-updated-1280x720.png)

### BUG-V211-FUNC-003 P0 生产需求“生成 MPS”仅产生页面状态，缺少正式计划事实

- PRD 依据：5.1、7.4.5、13.1；正式需求须经过校验/审批，并形成可查询 MPS/MRP 结果、来源关系和任务状态，不能仅提示成功。
- 步骤：生产管理进入“主计划(MPS) / 生产需求池”，对 `PD-260620-01` 点击“生成MPS”。
- 实际结果：页面立即 Toast“已生成 MPS 主计划”，需求状态改为“已生成MPS”；页面未展示正式需求 UUID、校验/审批、任务 ID、求解状态、求解器版本或来源追踪事实。
- 预期结果：按正式生产 API 创建并查询计划任务，只有成功结果覆盖目标需求后才允许认定 MPS 完成。
- 补充：本轮操作改变了该本地演示需求的状态。

### BUG-V211-FUNC-004 P1 租户选择刷新后丢失

- PRD 依据：8.4、9.1、13.5；租户上下文必须稳定并限定数据范围。
- 步骤：在顶部切换为“华东精工制造”，刷新页面。
- 实际结果：刷新前选择为华东精工制造，刷新后自动恢复为上海万申工业集团。
- 预期结果：在有效会话内恢复用户最后一次合法租户选择，或通过明确规则提示租户上下文已重置。

### BUG-V211-FUNC-005 P0 切换租户后仍展示上海租户业务数据

- PRD 依据：8.4、9.1、13.5；业务列表、指标、AI 结果必须按租户隔离。
- 步骤：切换为“华东精工制造”，观察工作台业务指标和实时动态。
- 实际结果：租户选择器已显示“华东精工制造”，工作台仍展示“客户：上海万申产业”等上海业务事实。
- 预期结果：所有业务指标、单据和 AI 查询上下文切换到华东租户，且不得泄露上海租户数据。
- 证据：[租户数据截图](evidence/v211-tenant-data-leak-1280x720.png)

### BUG-V211-FUNC-006 P2 销售订单子页标题与当前页面不一致

- 步骤：直达 `?module=sales&tab=orders`。
- 实际结果：订单表格和订单页签正确显示，但一级标题仍为“销售监控舱”，副标题仍为监控舱说明。
- 预期结果：标题和说明应与销售订单页面一致，避免用户误判当前位置。
