# AI 数据分析

提供经营决策舱、数据问答、归因树与推演沙盘页面。前端只展示业务后端结果，不编写 prompt、不执行 SQL、不直连 AI 服务。

- 数据来源：`aiApi.listInsights`、`aiApi.nl2sql`，均通过业务后端。
- 缺少聚合指标、历史序列、归因或推演契约时保留组件，展示缺失状态，不生成示例业务事实。
- SQL 预览与已执行查询结果分别展示；请求失败清除旧结果并保留问题和重试入口。
- 新功能顺序：定义 OpenAPI 契约 → AI 服务实现及自测 → 后端 client 和业务接口 → 前端对接 → 补文档。

前端验证：在 `frontend/` 执行 `npm run test:business-facts`。测试使用受控 API，不代表数据库端到端验收。
